# Keputusan — Tahap 1

`AGENT.md` tetap acuan utama. Catatan ini membedakan kontrak produk dari kemampuan fondasi saat ini.

| Keputusan                            | Dasar dan batas                                                                                                                                                                                                                                                                                                                          |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Desktop Windows 10/11 x64, offline   | Tauri 2, Vite/React/TypeScript; tanpa web backend, DB, akun, telemetri, CDN, atau koneksi remote saat runtime. Dev Vite memakai server lokal.                                                                                                                                                                                            |
| Identifier final `id.republika.game` | Sudah dikonfirmasi eksplisit oleh pemilik pada penugasan ini; cocok dengan konfigurasi. Jangan diubah setelah rilis.                                                                                                                                                                                                                     |
| Fixed-point untuk indikator          | Runtime ×10, kas integer miliar; penulis memakai satuan tampilan dan triliun. Validasi presisi mendahului konversi; `roundTenths()` half away from zero. Koefisien baseline tetap angka desimal; bukan semua angka runtime fixed-point.                                                                                                  |
| Hash konten SHA-256                  | `computeContentHash()` menghash definisi hasil parse/konversi. Koleksi fraksi, kementerian, kebijakan, event, arketipe disortir menurut ID; key objek disortir rekursif, properti `undefined` diabaikan. Array bersarang mempertahankan urutan. JSON kanonis dienkode UTF-8, digest berupa hex. Hash bukan tanda tangan atau anti-cheat. |
| Konten dibundel statis               | `contentBundle.ts` mengimpor JSON eksplisit. File baru wajib didaftarkan; CLI disk dapat melihat file yang belum masuk bundle. Tidak membaca folder konten runtime.                                                                                                                                                                      |

Semantik engine belum tersedia.                                                                                                                                                     |
| Mock bukan simulasi                  | UI mempresentasikan 20 kuartal; skenario JSON placeholder masih 4 kuartal. Pilihan mock tidak membuktikan efek, voting, atau laporan engine.                                                                                                                                                                                             |
| Storage belum persisten              | `MemoryStorage` berfungsi dalam memori; `TauriFileStorage` stub Tahap 1. Preferensi UI hanya sesi. File I/O atomik, autosave, backup, dan migrasi ditunda sesuai tahap, bukan dianggap selesai.                                                                                                                                          |
| Font lokal                           | Aset font disertakan beserta lisensi OFL. Tidak mengambil font dari CDN.                                                                                                                                                                                                                                                                 |
| GDD/TDD konversi historis            | PDF sumber (89.610 byte; header `%PDF-1.4`) dikonversi seluruh 9 halaman: GDD halaman 1–4, TDD halaman 1 dan 5–9. Sampul/daftar isi bersama diduplikasi; penomoran, tabel, pseudocode dan rancangan web/API/DB historis dipertahankan. Addendum v0.3 tetap menimpa; konversi bukan klaim implementasi.                                   |
| Gate berbasis bukti aktual           | Workflow tersedia bukan bukti run GitHub hijau. Instalasi artifact dan ukuran RAM oleh pemilik masih pending; tidak ada angka performa rekaan.                                                                                                                                                                                           |

## Tahap 2 — Engine

Keputusan aturan yang tidak dirinci `AGENT.md` §5. Semua dipilih sebagai opsi paling sederhana dan dapat dikoreksi pemilik sebelum UI dibangun.

| Keputusan                           | Isi                                                                                                                                                                                                                                     |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fixture, bukan konten               | `content/` masih placeholder, jadi engine diuji dengan `packages/game-data/fixtures/slice/` (3 kebijakan, 3 fraksi, 1 event). `content/` tidak disentuh.                                                                                |
| PER_TURN mulai kuartal lolos        | Durasi N = N kali efek PER_TURN; kuartal lolos dihitung. Penjaga `lastTickedTurn` mencegah efek ganda.                                                                                                                                  |
| DELAYED dihitung dari kuartal lolos | `delayTurns: d` dari kuartal N jatuh di kuartal N+d; efek tertunda kebijakan memakai pengali kementerian saat jatuh tempo.                                                                                                              |
| Cooldown                            | Cooldown yang dibuat pada suatu kuartal tidak berkurang di kuartal itu. Voting gagal di K1 → ditolak di K2, boleh di K3.                                                                                                                |
| Biaya per kuartal                   | Dipotong di baseline untuk setiap kebijakan yang berjalan kuartal itu (termasuk yang baru habis).                                                                                                                                       |
| Snapshot awal giliran               | Modifier bersyarat **dan** effectiveness untuk pengali kementerian dibaca dari state awal kuartal.                                                                                                                                      |
| Pengali kementerian                 | `0,8 + 0,4 × (eff − 40)/50` dihitung eksak sebagai `(60 + eff)/125`; kategori → kementerian pertama urut ID.                                                                                                                            |
| Baseline serentak                   | Semua rumus baseline membaca nilai awal langkah 8; urutan pencatatan inflasi, pengangguran, persetujuan, pertumbuhan, kas, penalti kas, reversi fraksi. Reversi dukungan fraksi 10% ke `baseSupport` memakai `factionSupportReversion`. |
| Kementerian +1                      | Per kebijakan sedomain yang berjalan kuartal itu; clamp 40..90 di normalize.                                                                                                                                                            |
| Respons event                       | Boleh diganti sebelum akhir kuartal; efek PER_TURN pada opsi event berlaku sekali; tanpa pengali.                                                                                                                                       |
| Kuartal terakhir                    | `turn` tidak melewati `maxTurns`; status menjadi `completed`. Arketipe ditunda ke Tahap 4.                                                                                                                                              |
| Lobi                                | Kas dipotong di langkah 3; bonus tercatat di ledger (`LOBBY_BONUS`, jenis VOTE) dan tidak mengubah dukungan permanen; `lobbyThisTurn` dikosongkan di akhir kuartal.                                                                     |
| Ringkasan laporan                   | `summary` dari engine kosong; kalimat Indonesia disusun UI dari data terstruktur (teks UI di `copy/id.ts`).                                                                                                                             |
| Skema state                         | Ditambah `seed`, `commandIdsThisTurn`, `lastTickedTurn`, `DelayedEffect.sourceType/createdTurn`; ledger memakai `order/sourceType/target/unit/before/delta/after`. `stateVersion` tetap 1 karena belum ada save pemain.                 |
| `roundTenths`                       | Menormalkan galat biner (`toPrecision(12)`) agar 1,15 → 1,2; hasil konversi konten tidak berubah.                                                                                                                                       |
| Hash state                          | cyrb128 atas JSON kanonis (bukan kriptografis), cukup untuk uji determinisme; PRNG sfc32 dengan seed `seed:turn`.                                                                                                                       |

## Tahap 4 — Sistem lengkap

| Keputusan                | Isi                                                                                                                                                                                                                                                                                 |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Drift fraksi (ruleset 3) | Δ = reversi ke dukungan dasar + `factionApprovalInfluence` × (persetujuan − jangkar). Parameter opsional di `baseline.json` dengan default 0,05 karena `content/` dilindungi. Fixture naik ke ruleset 3. Kode ledger `BASELINE_SUPPORT_REVERSION` diganti `BASELINE_SUPPORT_DRIFT`. |
| Hash konten              | Default parameter baru ikut ter-hash, jadi `contentHash` konten placeholder berubah walau file JSON tidak berubah.                                                                                                                                                                  |

Bentuk state berubah sehingga snapshot `slice-4q` diperbarui (ruleset tetap 3: dinamika tidak berubah).                                           |
| Nama statistik arketipe  | Didefinisikan sekali di `@republika/shared` (`parseArchetypeStat`) dan dipakai engine maupun `content:check`.                                                                                                                                                                       |
| Dampak keputusan         | Σ                                                                                                                                                                                                                                                                                   | delta | / rentang domain indikator, per sumber (kebijakan atau event). | Warna Laporan Akhir      | Netral (tanpa hijau/merah) agar tidak memberi label baik/buruk.                                                                                                                                                                                                                     |
| E2E 20 kuartal           | Build `vite build --mode e2e` mengganti `maxTurns` menjadi 20 lewat `define`; build rilis tidak terpengaruh.                                                                                                                                                                        |
